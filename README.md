# Day & Night ✦ Matcha & Coffee

موقع طلب مسبق (استلام) لـ **Day & Night**، وكل بياناته في ملف **قوقل شيت** واحد.

| الملف | وش هو |
|---|---|
| `index.html` + `app.js` | صفحة العملاء: المنيو، نهار/ليل، اختبار «مين أنتِ اليوم؟»، كوب الميلاد، النجوم، الطلب وتتبعه |
| `admin.html` | لوحة المحل (بكلمة مرور): الطلبات، المتوفر، إيقاف الطلبات، صرف مشروب مجاني، تبليغ العميلة |
| `config.js` | رابط الربط مع قوقل شيت (`API_URL`) |
| `shared.js` / `style.css` | الأدوات والتصميم المشترك |
| `apps-script/Code.gs` | الكود اللي ينحط داخل قوقل شيت |
| `images/` | صور المشروبات |

> إذا كان `API_URL` فاضي، يشتغل الموقع في **وضع العرض**: الطلبات تجريبية وتنحفظ في المتصفح بس، وكلمة مرور اللوحة `dn`.

## طلبات صاحبة المحل (مطبّقة)
- كل مشروب له إضافاته الخاصة (عمود «الإضافات» في تبويب المنيو).
- القهوة (Ice Drip و Hot V60) بدون إضافات وبدون حليب.
- **Ice Cream Matcha** مشروب مستقل: الحليب Original فقط، والإضافة Syrup فقط.
- إضافة الآيس كريم انشالت من باقي المشروبات.
- **D&N Matcha**: اختيار نوع الحليب بدون زيادة بالسعر.

## خطوات الربط (مرة وحدة)

### ١. ملف الشيت (على حساب قوقل حق المحل)
1. افتحي [sheets.new](https://sheets.new) وسمّي الملف «Day & Night — إدارة».
2. **Extensions ← Apps Script**، امسحي الموجود، والصقي `apps-script/Code.gs` كامل، واحفظي.
3. اختاري الدالة **`setup`** واضغطي **Run** ← **Review permissions ← الحساب ← Advanced ← Go to … (unsafe) ← Allow**.
   (يطلب صلاحية قوقل درايف عشان يحفظ صور أكواب الميلاد في مجلد «Day & Night — صور أكواب الميلاد».)
4. بتلقين التبويبات جاهزة: المنيو، الإضافات، الحليب، الإعدادات، الطلبات، النجوم.

### ٢. النشر كـ Web app
**Deploy ← New deployment ← Web app** · Execute as: `Me` · Who has access: `Anyone` ← **Deploy** وانسخي الرابط (ينتهي بـ `/exec`).

### ٣. ربط الموقع
الصقي الرابط في `config.js` وارفعي التعديل:
```js
window.DN_CONFIG = { API_URL: "https://script.google.com/macros/s/XXXX/exec" };
```

### ٤. النشر على Cloudflare Pages (مجاني)
1. [dash.cloudflare.com](https://dash.cloudflare.com) ← **Workers & Pages ← Create ← Pages ← Connect to Git** ← اختاري الريبو.
2. **Project name:** `dayandnight` (يصير الرابط `dayandnight.pages.dev` إذا الاسم متاح).
3. Framework: `None` · Build command: فاضي · Output directory: `/` ← **Save and Deploy**.
4. لوحة المحل على `/admin.html`. أي تعديل على `main` ينشر لحاله خلال دقيقة.

### ٥. الدومين
- **مجاني:** `dayandnight.pages.dev` من Cloudflare، بشهادة أمان (https) جاهزة.
- **دومين خاص (.com):** من Cloudflare Registrar تقريبًا 10.5 دولار بالسنة (حوالي 40 ريال)، نفس السعر عند التجديد.
  يتسجل باسم المحل وإيميله، وبعدها من المشروع: **Custom domains ← Set up a custom domain** ويرتبط لحاله لأن الدومين في نفس حساب Cloudflare.
- **.sa:** يحتاج أوراق رسمية (مثل السجل التجاري) من المركز السعودي للمعلومات الشبكية.

### ٦. قبل الإطلاق
- في **الإعدادات**: غيّري **كلمة مرور اللوحة**، وعدّلي الدوام ويوم الإجازة ومكان الاستلام ورابط اللوكيشن وبيانات التحويل.
- راجعي الأسعار، خصوصًا **Ice Cream Matcha** (حطيته 24 مؤقتًا).
- جربي طلب من جوالك، وتأكدي إنه يوصل للوحة ويطلع في تبويب «الطلبات».
- حطي رابط الموقع في البايو (تيك توك وإنستقرام).

> ⚠️ إذا عدّلتِ `Code.gs` بعدين: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** عشان يبقى نفس الرابط.
> تعديل محتوى الشيت (أسعار، أصناف، إضافات، إعدادات) يطبق على طول بدون أي شي.

## الشيت: وش يعدّل المحل؟

| التبويب | الاستخدام |
|---|---|
| **المنيو** | `متوفر`: نعم / لا. `الصورة`: اسم ملف من `images` أو رابط قوقل درايف. `الحليب`: اختيار بسعر / اختيار مجاني / أوريجينال فقط / بدون. `الإضافات`: معرفات الإضافات المسموحة بينها فاصلة (فاضي = بدون إضافات) |
| **الإضافات** | الاسم والسعر والتوفر لكل إضافة |
| **الحليب** | أنواع الحليب وسعر كل نوع (يُحسب بس للمشروبات اللي حليبها «اختيار بسعر») |
| **الإعدادات** | الدوام، الإجازة، إيقاف الطلبات، البانر، عدد النجوم، مكان الاستلام، اللوكيشن، التحويل، كلمة المرور |
| **الطلبات** | تنضاف تلقائيًا، فيها رابط صورة كوب الميلاد إذا العميلة رفعت صورة |
| **النجوم** | رقم كل عميلة وعدد نجومها، ويتعدل يدويًا لو احتاج |

## النجوم ✦
- كل مشروب = نجمة، محفوظة برقم الجوال.
- لما توصل للعدد المحدد (3)، يطلع للعميلة بالسلة خيار «أرخص مشروب مجانًا»، والخادم يتحقق وينقص النجوم.
- تقدرون تصرفون مشروب مجاني يدويًا من اللوحة.

## ملاحظات تقنية
- الأسعار تنحسب في الخادم من الشيت، فما أحد يقدر يتلاعب فيها من المتصفح.
- الطلبات تتسجل بـ `LockService` عشان ما تتكرر الأرقام.
- اللوحة تتحدث كل 10 ثواني وتطلع صوت مع كل طلب جديد.
